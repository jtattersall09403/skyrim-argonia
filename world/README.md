# world
The imported world: places, people, quests, dialogue data, hydrology, routes, stats tables, lore (decision 0009). `world/sources/` is the source of truth the generators read; `world/schemas/` its schemas. Written lines under `sources/dialogue` are reference only (0024 §7). Never: game or mod files, the Morrowind corpus (private), generated records (those are `plugin/`).
