# 0.2: Our stack on the game machine

**Goal.** Every dependency the plan names, installed on our Windows game machine by one script as a profile,
on the pinned runtime, with behaviours generated, a smoke scene that walks, swings, dodges, climbs, swims, sails
and opens every menu, and the frame-time and latency record with the whole stack loaded. This is the stack the
first place runs on; it is also the seed of 3.4's installer, which is not built now (decision 0029 §5).

**Starting state (2026-10-29).** The game machine runs Skyrim SE 1.7.104.0 offline (0.0 pinned the Steam
manifest), with the 0.0 souls-like overlay: `infra/gpu-box/combat_test_stage.py` stages mods from
`combat-test-mods.json` through the Nexus API and `combat-mode.ps1` lays them over Data and takes them off
exactly, Pandora included; the controlmap in DS1's layout; Crash Logger; the stream behind the owner's gate;
`infra/gpu-box/run.sh` drives the machine from the build VM over SSH. Nexus Premium is held
(`NEXUS_API_KEY`). The reuse audit (`docs/research/2026-10-29/reuse-audit.md`) records each candidate's runtime
support, with UNVERIFIED rows to re-check here.

**Read first.** Decisions 0002, 0003, 0006, 0012, 0014, 0028, 0029; the audit's rows for every mod below;
[stream-and-combat-stack](../../research/2026-10-28/stream-and-combat-stack.md); `infra/gpu-box/README` facts.

## Deliverables

### a. The runtime pin, confirmed
- 1.7.104 is the pin (decision 0002; the owner confirms O-3 on the evidence here). A mod that does not load on
  it is replaced by the audit's alternative or dropped, with the loss written into the brief that needs it. A
  rollback to 1.6.1170 happens only if a *core* row (SKSE, Address Library, Pandora, PrismaUI or the Dear Diary
  family) cannot be made to work, and is a decision record.

### b. The dependency manifest and the profile
- `data/dependencies.json`: every mod, with name, source (Nexus mod and file id, or ModDB), exact version, file
  hash, permission summary, AI clause, why we need it, which chunk depends on it, required or optional, runtime
  support, known conflicts, and which of our binaries link or fork it (0015). Grouped:
  - **core:** SKSE, Address Library, Crash Logger, PapyrusUtil, po3 Papyrus Extender, ConsoleUtil Extended,
    Fuz Ro D-oh, MCM Helper, SkyUI 6 (the Dear Diary family needs SkyUI 5.2SE: check it still skins SkyUI 6,
    else SkyUI 5.2SE is the pin), Pandora, OAR, AMR, Payload Interpreter, XPMSSE;
  - **combat (the 0.0 stack):** SkySA with the Elder Souls sword, Precision, TDM, TrueHUD, TK Dodge RE with
    Dynamic Dodge Animation and IFrame Generator, Elden Parry, Rim Parry and Execution, One Click Power Attack
    NG, Modern Stagger Lock, MaxsuBlockOverhaul, OAR-added Stamina Cost;
  - **traversal (owner, 2026-10-29: from the start):** FreeClimb 193552, Swimming Extensions 189821, Sailable
    Ship VR and SE 72070, EVG Animated Traversal; SkyParkour only if it coexists with FreeClimb;
  - **soul and UI:** Custom Skills Framework, PrismaUI (pinned), Dear Diary 23010 with Wood and Paper 44174 and
    the Oblivion-like Loading Menu 38708, Flat World Map Framework, No Google Maps, Magic Expanded 133435 (a
    check for 2.9), Community Shaders with the features 2.W3 and 4.6 need;
  - **the land and the places (decision 0028):** Tropical Skyrim SSE 78044 as the land; Black Marsh & Valenwood,
    the Xanmeer tileset, King of the Murkmire, Sign of Cipactli and the other Black Marsh mods for buildings,
    props and creatures, as the imported world's registries reference them;
  - **dev only, never shipped:** SkyLink AI 175682, houseCARL 181738.
- `infra/gpu-box/stack.py` (grows from `combat_test_stage.py`): fetches every manifest row through the Nexus API
  (ModDB rows: a listed manual download, cached privately in S3 after the first fetch), verifies hashes, lays
  them as the **Argonia profile** over a clean Data (the overlay with exact undo, as 0.0 does), writes
  `plugins.txt` and `loadorder.txt`, runs Pandora on the machine, and records the installed set's hashes.
  houseCARL reads the result for overrides, conflicts and the SKSE layer; its report is the conflict list.
- **Build-VM masters:** the dependency plugins (ESM/ESP/ESL only) and mesh path lists synced to
  `$ARGONIA_GAME_ROOT/Data` on the build VM, so ArgoniaGen can master them (0.4).
- **Acceptance:** `stack.py install` on the game machine from a bare Data reaches the main menu with every row
  loaded (SKSE's plugin log shows each DLL); `stack.py verify` matches every hash; houseCARL lists no unresolved
  conflict; the manifest has no unknown AI clause and no row without a permission summary.

### c. The smoke scene, with the whole stack
- **First, the dodge and the pad, fixed** (owner, 2026-10-29, from the 0.0 sessions): the player "just rolls in
  place without moving". Dynamic Dodge Animation (79598) requires **Animation Motion Revolution (50258)** and Open
  Animation Replacer (92109); 0.0's list has OAR but not AMR, and without AMR an animation's motion data does not
  move the actor, which is this symptom. Install AMR; follow 79598's page and videos for how it is meant to be
  installed and set (its TK Dodge RE branch, 8-way rolls, the backstep when stationary); check TK Dodge RE's
  own hotkey ini so the dodge is **B only** (its default gamepad hotkey shadowed LB); **LB is block** (LT may stay
  block too); **RT is the heavy attack** through One Click Power Attack NG's gamepad key (it did not fire from RT;
  fix its key setting and prove it); **lock-on is the right stick click** through TDM's own target-lock hotkey
  (right thumb, DirectInput 273), separate from Toggle POV. Each proved in game by the runner's events and a
  still sequence: a roll covers distance in all eight directions, a backstep from standstill, RT power-attacks,
  LB blocks, RS locks on. The pad layout record in `infra/gpu-box/controlmap.py` and the mod inis are the
  deliverable; the owner's feel check follows in the Part 0 check.
- A save at the Riverwood test place (0.0's) and one at the Embershard camp, played by a script through the
  console and SkyLink where it already works (0.3 makes this the runner): load, walk, draw, swing, roll, block,
  parry, lock on, climb a wall (FreeClimb), swim and dive (Swimming Extensions), use a ladder, board and sail the
  Sailable Ship boat, open every menu (the Dear Diary theme showing), quit. Crash Logger is read after.
- **Acceptance:** the scene passes twice in a row with no crash and no Papyrus error spam; each menu's still
  shows the paper theme.

### d. Frame time and latency, recorded
- With the stack loaded, in a dense Tropical Skyrim scene (the Riverwood place is enough until 0.4's block
  exists; re-measured there): median and 1% low frame time at 1080p on the current instance type, CPU or GPU
  bound, Community Shaders on and off; the stream's press-to-screen latency re-measured by 0.0's client page.
- **The bar:** 60 fps median and 45 fps 1% lows, latency within 10 ms of 0.0's record. The bar is written
  beside every later feel verdict and never bent: a DS1 window is not retuned for a laggy stream.
- **Acceptance:** the numbers in `infra/README.md` and decision 0007; the instance type chosen.

### e. Saves, costs, permissions
- Saves on the game machine backed up to S3 after each session and on stop; a restore script.
- `tools/cost_report.py` in every check-in (0.1).
- **Permission requests, drafted for the owner** (O-17 then O-5; not gating): first the evidence the owner
  already holds; then one short message per author whose terms say "ask" or whose AI clause is unknown (the
  manifest's rows name them), in a secret gist the owner copies from. Replies land in the sourcing register.
  Building continues meanwhile; a refusal replaces the mod and re-kits what used it.

## Acceptance (the gate)
`stack.py install` and `verify` green; the smoke scene twice; the bar and the latency record written; saves round
trip; the manifest complete; the drafts posted.

## Loops (docs/loops.md)
None: a tooling chunk; the smoke scene and the measurements are its proof.

## Risks and fallbacks
- **A core mod fails on 1.7.104:** the audit's alternative; else the rollback decision in §a.
- **Pandora fails on the machine:** pin its version; Nemesis as the fallback.
- **Dear Diary does not skin SkyUI 6:** pin SkyUI 5.2SE.
- **Frame time misses the bar:** lighter Community Shaders settings, then a larger instance type, each measured.

## Deliberately out of scope
Any installer for players (3.4); any game system; the bridge and scenes (0.3); our records (0.4).
