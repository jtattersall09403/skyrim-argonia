# 3.5: First playable

**Goal.** The two Part 3 de-risks are proved: the owner's full run from one tap, and a stranger's install on their
own PC. Then the owner decides whether the slice is released publicly as early access.

**Starting state.** Written by the agent that closes the last of 3.1–3.4.

**Read first.** The Part 3 README; decisions 0003, 0007, 0015.

## Deliverables
- **The device matrix:**
  - the owner's phone (folded and unfolded, Wi-Fi and 5G) and the Mac, through the stream;
  - a Windows PC at the documented minimum (the 3.4 Windows test machine);
  - Linux with Proton.

  On each, record boot time, load times, frame time and the stream latency.
- **The stranger's install:** one outside player (the owner finds them) installs from the public docs and reaches
  the open world. Their notes come through a GitHub issue template. The planner fixes the docs and the installer
  from them.
- **Early access (owner call O-20):** whether to publish the slice now (a Nexus page as "early access",
  4.6's page text in draft). The recommendation is yes once the stranger's run is clean: real players find install
  problems that no test machine does.

## Acceptance
