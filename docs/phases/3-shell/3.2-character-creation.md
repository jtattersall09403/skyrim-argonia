# 3.2: Character creation

**Goal.** Morrowind's character creation on Argonia's data: name, race (Skyrim's face sliders behind our frame),
class (presets, custom, or Morrowind's questions rewritten for Black Marsh), birthsign, then review. It sits
inside the opening as Morrowind's census scene does (soul contract C12).

**Starting state.** Written by the agent that closes 3.1. Expected: every race, class and birthsign record exists
(2.1).

**Re-check before starting:** RaceMenu (only if the face sliders need it) and its licence.

**Read first.** Decision 0005 (C12); imported `76-stats-progression.md` ~398–413; old 0054, 0096
(inherited-rulings); the old 3.3 brief (imported).

## Deliverables
- **The flow** (PrismaUI): name → race (vanilla face sliders behind our frame) → class → birthsign → review.
- **Classes:** the 18 presets, a custom class (5 major, 5 minor, a specialisation, 2 favoured attributes), and the
  question-generated class.
- **Class start bonuses** as 2.1 defined them.
- **Diegetic placement** in the opening (3.3): each step is reached from a person or a document in the scene, as
  Morrowind's census office does.
- The studio character (0.4) is now built by this flow's own code path with fixed answers, so the studio and the
  game share it.

## Acceptance
- L3 harness tests for each step at four viewports.
- The new-game journey reaches the open world with the chosen sheet on the game runner: every derived value
  read back matches the formulas.

## Loops (docs/loops.md)
- **Subsets:** each step (L3, L4).
- **Joins owned:**
  - chargen → the sheet → the first control;
  - the face sliders ↔ our frame (**L5, reason: the hand-off between vanilla sliders and our view shows only in
    motion**).
- **Journey:** a new game with each class kind (preset, custom, questions), to the first control (game runner;
  the core runner checks the sheet).

## Deliberately out of scope
The opening's story and places (3.3).
