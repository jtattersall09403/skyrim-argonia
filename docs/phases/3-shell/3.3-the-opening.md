**Goal.** A new game starts Argonia's story and ends in the open world. The opening is the old main quest's: "a
prisoner on a work detail near Stormhold / Alten Corimont, attacked by Sithis radicals, recorded dead, recruited
by the Veiled Reed" ("The Eye and the Root"). It is set at the Opening Work Camp, with the vastei tutorial and
the route to the first town. The owner is hands-on throughout (owner call O-10).

- the main quest's first stages are imported data (2.12 ran the slice's share).
