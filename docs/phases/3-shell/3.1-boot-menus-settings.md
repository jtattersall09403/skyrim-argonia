# 3.1: Boot, main menu, loading, settings and controls

**Goal.** Every surface between launching the game and playing it is ours, and every setting and control a player
needs exists. No vanilla Skyrim screen is seen in normal play: main menu, loading, settings, pause, wait and
credits.

**Starting state.** Written by the agent that closes 2.17.

**Re-check before starting:** PrismaUI and Infinity UI versions; JPEXS FFDec.

**Read first.** Decisions 0006, 0014 §7, 0017; the 2.2 UI map; the old 3.1 and 3.2 briefs (imported).

## Deliverables

### a. Every remaining vanilla menu
- Every remaining vanilla menu in the stack is restyled or replaced in the decision 0014 §7 order: a PrismaUI
  replacement, then our own original SWF, then an installer-time patch. A Bethesda or mod SWF is never shipped
  edited. The menus in scope:
  - MCM, the tween menu, the system menu, any journal tabs we kept;
  - crafting, lockpicking if kept, training, sleep and wait;
  - the loading menu, the main menu and the credits.
- Pelagiad is verified everywhere. Icons with no sourced equivalent are made with Fal.
- **Loading screens:** Black Marsh paintings (Fal-made or sourced) with loading facts from the text catalogue
  (old 0157: "the marsh does what the loading facts say").
- **The main menu:** the Argonia title, a Black Marsh background scene, Pelagiad. It offers continue, new game,
  load (rest saves only) and settings. In the dev profile, a **Studio** entry sits beside them.

### b. Settings, controls, pause and wait
- **Settings:** display, audio, subtitles, text size, difficulty (2.8), and the graphics quality bands for player
  PCs (Community Shaders presets).
- **Controls:**
  - keyboard and mouse, and the gamepad, with rebinding;
  - the phone through the stream: a Bluetooth pad or the stream client's touch overlay, whichever 0.2 G2
    recorded, laid out for the Magic V5 folded and unfolded.
- **Pause:** the PauseDeck. **Wait:** in settlements only (2.8 rules).
- **Accessibility:** text size, colour-safe HUD states, hold-to-toggle options.

## Acceptance
- A full menu sweep (every screen and tab, at 1080p and 720p and the phone shapes) passes the reader panel and an
  owner packet.
- Launch to the main menu in game shows no vanilla screen (stills at 1 s intervals, read by a reader).
- Every binding works on keyboard and pad (L4 inputs).

## Loops (docs/loops.md)
- **Subsets:** each menu (L3, L4); loading screens (L4 stills); settings (L2 persistence, L4); controls (L4 inputs).
- **Joins owned:**
  - launch → main menu → load (**L5, reason: the boot hand-off shows only in motion**);
  - settings → effect in game (L4);
  - pause → resume (L4).
- **Journey:** main menu → load the newest rest save → play → pause → settings → resume (game runner).

## Deliberately out of scope
Character creation (3.2); the opening (3.3).
