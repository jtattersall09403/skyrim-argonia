# Part 3: The game shell

**Goal.** The real game is something a player opens:
- **the path in:** install → boot → main menu → new game or continue → character creation → the opening → the
  open world (the slice);
- **where it runs:** the owner's phone and Mac through the stream, and a stranger's own PC;
- **what it de-risks:** the two things the studio never exercised, a first-time player and a first-time install.

**What this part is not.** It adds no gameplay system. Save and load are Part 2's (1.1, 2.17); the slice content
is Part 2's. A system found missing here is a Part 2 defect: fix it there, final-shaped. The studio stays the
place where everything is tested; this part builds the front door, not a second game.

## Part 3 exit (the owner signs)

- **The owner's run:** on the phone, from one tap, the owner starts a new game, makes a character, plays the
  opening into the open world, closes the browser, reopens it and continues.
- **The stranger's run:** one outside player installs from the public docs on their own PC (not the owner's box)
  and reaches the open world without help.
- **The release check:** no file outside the allowlist; three install paths verified.
