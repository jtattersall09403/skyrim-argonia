**Status.** todo. The row in [PROGRESS](../../PROGRESS.md) and this line move in the commit that changes them.

**Starting state (2026-10-31).**
- The owner's play test (owner-playtest-1.md, item 6): the default character has an Argonian body and a Nord head.
- A reader also saw the player's hair as neon yellow-green (lane-game-22.md).
- The full-body faces reader row in [checks.md](checks.md) (1.2) is owed.

**Diagnosis so far (2026-10-31, read-only).** infra/gpu-box/base_save.py starts a new game as Skyrim's default
character (a Nord) and then runs the console's `player.setrace ArgonianRace` (base_save.py:54). setrace swaps the
race and body but keeps the character's head parts, hair and tints, so the save carries a Nord head and the Nord
preset's hair on an Argonian body. The fix at the source: our plugin overrides the Player NPC_ record (Skyrim.esm
0x7) with ArgonianRace and the race's own default head parts and tints, so every new game starts Argonian with no
console swap; the player's face is built by the engine at run time (no FaceGen file). Then the walk save is remade
from 1.9's re-runnable command. To check in game: the race, head parts, hair and tint records the player carries.

**Read first.** Decision 0006 (no Nordic element), 0014 (FaceGen is made on the player's machine), the 1.1 seam's
player setup, the base save tool (infra/gpu-box/base_save.py), the race records in world/db.
