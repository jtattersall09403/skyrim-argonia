2. **Design:** one page in ui/DESIGN.md for the HUD. It covers:
   - the bars: frame, fill, damage trail, regeneration, low-health state;
   - vastei top left;
   - the notices, the lock-on cue, and any element from the inventory the game needs.
   The palette and type come from the theme.
   - Do a focused loop with eyes over this, fast iterations over stills on the build machine. See loops.md.
3. **Build** it in the HUD view at its final interface, wired to the sheet's values as today.
4. **Check in game:** stills and clips/temporal strips in play (use dev tools to trigger whatever you need so you can check the implementation, e.g. player taking damage so you can see the damage trail). If issues, go back to the fast build machine design loop and redesign until you're happy, then move onto 'check in game' again. Repeat until happy.
