# 1.6: A quest, the journal and directions

**Goal.** One imported quest runs as data through the final quest generator: talk starts it, a stage is
written to the journal, the giver's directions are in the journal and true on the ground, no marker points
anywhere, and the quest completes. This proves Morrowind's "follow the directions" works in Skyrim's quest
system (soul contract C7, C8).

**Starting state.** Written by the agent that closes 1.3. Expected: the dialogue runtime's first rung and three
Claywater people exist.

**Re-check before starting:** No Google Maps Skyrim and Flat World Map Framework versions.

**Read first.** [2.12](../2-slice/2.12-quests-journal-map.md) in full (the rules this first rung implements);
imported `docs/design/quests/85-condition-vocabulary.md`; old 0030, 0137, 0153 (inherited-rulings);
universal-modder's Skyrim field note on quests and dialogue generated from code (decision 0020 §4).

## Deliverables
- **Pick the quest:** one of the 38 staged imported quests anchored at Claywater Station or its block (or, if
  none fits, the one nearest it, re-sited with a recorded reason). It must have at least three stages, one
  dialogue-gated stage and one place to reach.
- **The quest generator** (2.12 §a), final shape:
  - stage graph → QUST records with stages, log entries, objectives and aliases;
  - generated Papyrus **begin** fragments only (end fragments on Goodbye lines are unreliable);
  - non-native conditions and actions call ArgoniaCore;
  - fail-forward if the giver dies.
- **Directions** (2.12 §a): a small route graph of the block (its road, the landmarks), the giver's direction text
  generated from it into the journal, and the validator that walks the described route in data.
- **The journal view's first rung** (1.2): dated entries and the quest index. The topics index joins in 2.12.
- **No markers:** quest targets have no map or compass marker; the place's map marker appears only when reached
  on foot.

## Acceptance
- The quest runs start to end on the game runner.
- The direction validator passes. An L4 walk of the described route by teleport hops reaches the target within
  50 m of each described landmark.
- No marker exists (a state read of objectives' target data and the map).

## Loops (docs/loops.md)
- **Subsets:** the generator (L1, L2 stage walk); directions (L1 validator); the journal (L3, L4); markers (L4).
- **Joins owned:** talk → stage → journal entry (L2, L4); reach place → stage → map marker (L4); stage → save round
  trip (L2, L4).
- **Journey:** accept the quest in dialogue, reach the place, advance the stage, return, complete, read the journal
  (both runners).

## Owner check
In 1.8: "follow the directions in your journal, with no marker".

## Deliberately out of scope
The map views, the topics index, grantable markers and world registries (2.12); every other quest.
