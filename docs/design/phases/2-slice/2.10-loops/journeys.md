# Loop survey: the five 2.10 journeys (lane 2.10-j)

The owner plays stealth, crime and locks as journeys (0151, 0155). Each journey is
a script as data (`journeys/<id>.json`, the 2.9x schema in
lanes/2.9x/briefs/y-schema.md plus the stealth verbs below), driven by three
runners as docs/phases/2-slice/2.9x-loops/journey.md describes:

- **H-scene**: `packages/scene/src/interact/journey.ts` `runJourney` over the
  scene's composition (`createWalkCrime`, `createInteractSession` with its
  crime, locks and pickpocket hosts, `walkLockHosts`, the item session, the
  magic session and its flinch queue, the hostile observers on the notice
  service). Test: `packages/scene/src/interact/journey-session.test.ts`.
- **H-game**: the same scripts through the game's composition
  (`useWalkCrime`, `walkLockHosts` and `useWalkInteract` as `GameWorld.tsx`
  passes them). Test: `apps/game/src/journey.test.tsx`.
- **Pod**: superseded by 0155 and 0156: no agent-filmed journey strip; the
  owner plays the journeys deployed. Seam cuts are filmed instead (findings
  9 onward).

Stealth verbs (`do.action`): crouch{on?}, approach, pick{lock, tool?},
probe{lock, tool?}, take{lock|socket}, castOpen{lock}, pickpocket{npc, item?},
stop{npc}, pay{npc}, serve{npc}, resist{npc}, greet{npc}, strike{target},
bow-draw, shoot{target, missM?|lure?}, wait-for-search{seconds}, wait{hours},
save. Each takes the optional frame fields `place`, `hour`, `cell`, `near`
(who stands where, the headless stand-in for the cast's spots) and `seconds`.
`start.skills` is the tester's trained character (as `start.learned`), `start.seed` the walk's dice.

On demand only (`JOURNEY=1`): nothing here joins check.mjs, CI, visual:check's
default groups or any regular gate.

## How to run it

- `cd packages/scene && JOURNEY=1 npx vitest run src/interact/journey-session.test.ts -t stealth`
- `cd apps/game && JOURNEY=1 npx vitest run src/journey.test.tsx -t stealth`
- Pod: tooling/gpu-lane/README.md § The loop with `--spots lanes/2.10/j-shots/spots.txt`.
