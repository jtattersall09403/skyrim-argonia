# Archive: the Black Marsh & Valenwood version

From 2026-11-05 to 2026-11-26 the project was our story modded onto the world of the Black Marsh & Valenwood mod
(BM&V). The owner retired that version on 2026-11-26
([decision 0042](../decisions/0042-the-new-world-is-the-project.md)); the project is now the new world
([the plan](../PLAN.md)). These files are that version's phase plans, kept as they stood on the day and no longer
edited. Nothing here binds; read them only for how something was proved.

| File | What it was |
|---|---|
| [1-stack-in-bmv.md](1-stack-in-bmv.md) | Phase 1: the mod stack (soulslike combat, climbing, magic, the HUD) with BM&V as the default world. The stack itself carries on in the new world. |
| [checklists/1-checklist.md](checklists/1-checklist.md) | Phase 1's checklist. |
| [3-building-blocks.md](3-building-blocks.md) | Phase 3: each kind of quest change proved once. The blocks became the quest form's vocabulary ([blocks](../design/blocks.md)). |
| [4a-talk-to-everyone.md](4a-talk-to-everyone.md) | Phase 4a: a backstory and topics for every BM&V person. The method became the skills `place-people` and `dialogue-write`. |
| [talk.md](talk.md) | The design Phase 4a's talk pipeline ran from: why "E to talk" opened nothing, the talk tables and topic catalogue for BM&V's people. New-world people get their identities from `place-people` and their lines from `dialogue-write`. |
| [5-scale.md](5-scale.md) | Phase 5: scaling the story over BM&V's world. Replaced by the new world's phases nw-07 to nw-12. |

Before BM&V, the first week (2026-10-27 to 2026-11-05) built a total conversion with its own generated world and
systems; it was thrown away at the pivot of 2026-11-05 and is in git history only.
