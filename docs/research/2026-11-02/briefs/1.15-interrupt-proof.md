## Why (owner, 2026-11-02)
"Build VM workflow must be designed so nothing is lost on interrupts, including whatever 'the queue' is. Build
machine comes back online almost immediately after most interrupts so we lose little time." Today the VM was
reclaimed twelve times; each time every job_guard unit (builds, the game-machine chains, the waits) died with the
session, and the planner re-queued by hand from the lane ledger, losing 5–20 minutes and the queue's order each time.

## How
- Spool first: `job_guard.sh run` already writes `<name>.pid/.unit/.machine/.started/.rc` under ~/.argonia/jobs; add
  what a relaunch needs (`<name>.cmd` as an argv file, `.cwd`, `.env` for ARGONIA_* and PATH, `.seq` for the order,
  `.gpu` for the lock) and a state that distinguishes queued, running, done, stopped.
- Restore: a `tooling/job_resume.sh` run by a systemd --user unit at boot (lingering on for the ubuntu user; check
  `loginctl show-user ubuntu -p Linger`), which relaunches, in `.seq` order, every job whose state was queued or
  running and whose `.rc` is absent, through the normal `job_guard.sh run` path (so locks and queueing behave as
  before), and writes `~/.argonia/jobs/RESUMED-<boot-id>` with what it did; the planner's resume hook reads that
  instead of re-queueing.
- A job is relaunched from the start: say in docs/machine-moves.md that every job must be idempotent (checkpoints,
  `up_until`, step markers), and name the ones that already are.
- Do not edit tooling/job_guard.sh in the main tree while any job_guard process runs there (bash reads a script
  incrementally; `pgrep -af job_guard.sh`): develop in a worktree (`tooling/worktree.sh ~/wt-interrupt-proof`), test
  there, and return; the planner merges at a quiet moment and lays the unit.
- Golden rule 0034 does not apply (no Bethesda analogue); reuse first: systemd's own `Restart=` cannot survive a
  reboot for transient units, so the boot unit + spool is the minimum of our own.
- Commit small and often; return ≤ 25 lines: the spool fields, the restore rule, the measured restore time, what a
  job must be.
