# Lane 1.15-r6-stand-cache: the stand measures are cached by the build, not by gen.py

- `tools/journeys/measures.py`: `memo` caches eye_hits, clearance, grass_hits, water_share, frame_read, frustum_cover, stand_bad and ground_slope_deg per (measure, args rounded to 0.1 mm) in `out/journeys-cache/<build key>.sqlite` (WAL, one autocommit insert per new result, `INSERT OR IGNORE`; read into memory at open). Fixture `Build(...)`s are never cached.
- Build key = content of what the measures read (world/db object_form + ltex_grass, out/water/cells.jsonl, sizes of the `cy*.jsonl.gz` vegetation and land shards) + `MEASURE_VERSION`. Not gen.py, not the rest of the DB, not the other files in out/terrain/vegetation (checks.json, veg.stamp moved the key on every lane's run). Bump `MEASURE_VERSION` when a measure's maths changes.
- Removed: the per-stop json cache in gen.py (`_cached`, `_build_key`, out/journeys/cache). Stores of builds untouched for 3 days are pruned on open.
- Timings (shared box, load 5-7): refresh cold 324 s (road-stop's figure; 350 s measured here with the old cache cold); after the cache is filled and gen.py has a comment-only edit: 37 s (was 8.5 s only if gen.py was not edited, else cold). Remaining 37 s is not measure work: Build load, panel clearance, creature kinds, water search glue (ground_u, frame()).
- Tests: `tools/tests/test_journeys_measures.py` (hit, rounding, fixture builds uncached, version bump moves the key, two processes writing 300 entries each lose none = 450 rows). Equality check: 726 calls over 6 measures on the real build, cached vs uncached, 0 mismatches (clearance must return a tuple: `dec=tuple`).
- tests/journeys/*.yaml byte-identity to before could not be shown on a live tree: the ground was regenerated at 20:19 and other lanes moved the DB and shards during the runs; equality is shown per measure instead.
