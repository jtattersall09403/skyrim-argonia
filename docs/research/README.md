# Research kept from the first week

Facts about Skyrim, the mods, the machines and the writing method that would cost time to rediscover. A file is
evidence, not instructions; where a file and a decision disagree, the decision wins. Prices and versions go
stale; re-check before relying on one. Most files were lane hand-offs written for the old plan: read them for
their facts and ignore their process.
