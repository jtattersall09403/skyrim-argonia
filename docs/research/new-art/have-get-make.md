## 0. The method (the recipe; ten lines)

1. Name the thing every way: lore word, plain word, real-world thing, what a modder would call the file (grave-stake = "roadsign"; weir = "fence", "fishnet", "trap"; sap tap = "spigot"; EEC mark = "EECo"). Write the synonyms down.
2. Search all 40,968 rows of `out/places/catalogue/bases.jsonl` (49 plugins, vanilla and DLC and Creation Club included) on edid, name and model path; then the unreferenced files: `find ~/games/skyrimse/newworld-assets/*/meshes ~/.argonia/stack/MO2/mods/*/meshes -name '*.nif'` (28,880) by file name. Weapons and armour are catalogue rows too (kind clutter/static, bounds 0); search `weapons/` and `armor/` paths.
3. Search what we built and carried: `place.json` draft text, `agent-edits/*.json`, refs.jsonl (`why`, `cluster`), world.sqlite place_note/place.summary/source_place.description/travel_mode, source bundles. A thing may exist only as a COMPOSITION: record bases, arrangement and where it stands.
4. LOOK at every candidate: placed piece -> `look <place> at <id> [--high]`; unplaced base -> `assets render <model> <png>` (or a contact sheet). A name is never enough, either way. A capture failed only for "camera inside FXbirdOPreyNoNestACT" in Jal-Veesa is a false alarm when subject_seen is high (I used one: 0.866).
5. Check use: `use.json` over all refs (which drafted place places the base), flora/dressing/stock tables.
6. Only then Nexus (section 3 of the proposal and the lane reports; new `nexus_search.py` terms only for items they did not cover).
7. Verdict per item: HAVE (base key, where seen, what change uses it) / COMPOSE (recipe) / ADAPT (a recolour or small edit) / GET (named mod, what to check) / MAKE (what exactly is missing and why nothing held or composed will do) / UNSEEN (not looked: what is needed).
8. "Not held" may be written only with: the synonym list, the three catalogue searches (edid, name, model), the disk-file search, the world/place search, and a look at the nearest candidates, all listed beside it.
9. A render that shows a magenta box or black is an unresolved model or texture: the verdict is UNSEEN for that base, never "not held".
10. Store the verdict, base keys and picture path beside the catalogue row (a "looked-at index", section 9) so the next search starts from labels.
