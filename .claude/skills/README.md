# Skills

- `quest-write`: design a quest record (shapes, principles, skill-use catalogue, brief and action-plan generators) from the story data and the lore (decisions 0024, 0025).
- `quest-review`: independent design critique of a quest record before any dialogue exists.
- `dialogue-write`: write one person's dialogue from a generated brief, with the ban linter, voices and the Morrowind corpus tools.
- `text-review`: one `reader` pass then the linter over changed player-visible prose.
- `cost-review`: periodic Claude usage and cost review from `tooling/session_tokens.py`.
- `grill-me`: stress-test a plan with the owner, one question at a time, after the repo has answered what it can (adapted from mattpocock/skills, MIT).
