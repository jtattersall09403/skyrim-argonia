# Elder Souls: Argonia

A free Skyrim Special Edition mod: our own world of the whole of Black Marsh, generated from Project Tamriel's
map and built from places carried out of the mods we depend on, with soulslike combat from the Nexus collection
[Soulsborne Combat](https://www.nexusmods.com/games/skyrimspecialedition/collections/xyf1u3), free climbing, and
our own storyline, quests and factions. Built by Claude Code agents on AWS; the owner plays it streamed to a
browser.
